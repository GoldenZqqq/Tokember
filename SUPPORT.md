# Support

## What Tokember is

Tokember is a **self-hosted**, personal multi-device dashboard for AI agent token
usage and cost. There is no hosted SaaS support queue.

## Getting help

1. Read the [README](./README.md) quick start, [privacy](./docs/privacy.md), and [FAQ](./docs/faq.md).
2. Search existing GitHub Issues for similar problems.
3. Open a new Issue with:
   - OS and Node/Python versions
   - Collector kind (native TS / Hermes)
   - Which tools you collect (Claude Code, Codex, OpenClaw, Pi, …)
   - Logs with **secrets redacted**

## Security issues

Use [SECURITY.md](./SECURITY.md) — do not post exploit details in public Issues.

## Commercial / production consulting

Not offered by default. Maintainers may respond to community Issues on a
best-effort basis.
